THE SETTLERS - Freeserf for the Amiga with a graphics card
==========================================================

Version 0.111 (beta), 30.10.2026

The Settlers (Die Siedler, Blue Byte 1993) on an Amiga with a graphics
card (Picasso96) and a 68040/68060, at up to 800x600 (4:3) or 960x540
(16:9). It is based on
Freeserf, the open source version of the game (GPL-3.0). The graphics,
sounds and music come from the original Amiga disks, which you need.


REQUIREMENTS
------------

- an Amiga 500 / 1200 / 3000 / 4000 with a Warp accelerator (Warp560,
  Warp1240, Warp1260, Warp1260 Extreme, Warp7060): the port is made and
  tested on these cards, and the fast graphics of the Warp give the
  resolutions and frame rates of this text. Other Amigas with a
  68040/68060 and a Picasso96 card run the game, but slower.
- tested on: A1200 + Warp1260 Extreme (68060, 100 MHz) and
  A4000 + Warp7060 (68060)
- AmigaOS 3.x, Picasso96 with 8-bit screen modes, about 32 MB Fast RAM
- the original The Settlers Amiga disks (3 disks)


GETTING STARTED
---------------

1. Copy the Settlers drawer to your hard disk.
2. Copy these files from the original disks to Settlers/data/amiga:
     from disk 3: gfxheader, gfxfast, gfxchip, sounds, extro
     from disk 2: gfxpics, music
3. Double-click the Settlers icon.

The game data is not in this archive - it comes from your disks.

Start picture (optional): the file data/start.iff - any IFF ILBM picture of
up to 8 bitplanes, shown while the game starts (at least 4 s, with the
music when it is on), scaled down to the screen.
Without it the screen is black while the game starts.


CONTROLS
--------

  mouse                    everything in the game (as in the original)
  right button + move      scroll the map
  cursor keys              scroll the map
  Z, mouse wheel           the map magnified: x2 (above 400x300), x3 (800x600
                           and 960x540); none on 640x360;
                           the wheel up/down by a step, Z in turn
  P                        pause (again: continue), PAUSE on the screen
  1 ... 5                  panel buttons
  B                        building sites
  Tab                      next message; in a LAN game: the chat box
  +                        game speed: x1.5 / x2 / x2.5 / x3
  -                        slower, down to x0.5
  0                        normal speed (x1)
                           (a speed other than x1 is shown top right)
  M / S                    music / sound effects on and off
  Ctrl+Z                   quick save
  Esc                      close a box in the game
  Shift+Esc, Ctrl+Q        quit
  I                        a box with the keys (also the I button of the
                           settings box)
  QUIT (settings box)      leave the game for the start menu
  QUIT (start menu)        quit (after a question)
  F9                       screenshot to RAM:Settlers-shot.ppm
  F10                      save the state for a bug report


SETTINGS IN THE GAME
--------------------

Options:
  Messages   how many messages (None, Few, Most, All)
  Aspect     the shape of the screen, 4:3 or 16:9 (a click changes it;
             it always starts at the smallest resolution: 400x300 /
             640x360)
  Screen     resolution: the arrows next to it change it at once, within
             the chosen aspect - 4:3: 400x300, 640x400, 640x480,
             800x600; 16:9: 640x360, 960x540; it is kept for the next
             start
Options -> Amiga:
  about the Amiga; with a Warp accelerator the CPU clock: MC68060 50-100
  MHz in steps of 10 (raising only on a rev. 6 - overclocking, may hang
  the system), MC68040 20-50 MHz in steps of 1
Options -> Advanced:
  Invert scrolling, Large numbers, Autosave, Stock box until occupied,
  Show FPS (frame counter in the corner)
Options -> Advanced -> VIDEO:
  Sand on new maps (the deserts of new maps: None, 10% of normal
    ... Normal, - + buttons),
  Rocks on new maps (the brown boulders of new maps, the same way),
  More kinds of trees (mirrored trees and birches, only the look),
  Wild boars (boars among the trees)

Settings are kept in Settlers.ini next to the game, saved games in the
freeserf drawer.


PLAYING OVER A NETWORK (LAN)
----------------------------

Two players on two Amigas (or an Amiga and an emulator, e.g. WinUAE or
Amiberry), and up to 2 computer players.

Needed:
- a TCP/IP stack (e.g. Roadshow) on both computers,
- the same version of the game on both (another version is turned away
  with a message),
- port 6810 (TCP and UDP) open between the computers; on a PC with
  WinUAE it has to be let through the Windows firewall.

The one who sets up the game (MASTER):
1. In the start box switch the game type to "LAN game" (the icon with
   LAN on it, third after New game and Start mission).
2. Set up the map as in New game: size, random number, computer players
   (player 1 is you, player 2 the other person). Sand and rocks of the
   map: Options -> Advanced -> VIDEO; the settings of this side count.
3. Start -> START SERVER. Type the name of the server (MASTER) and click
   RUN SERVER - the server announces itself in the network.
4. When the other player joins, their name, address and response time
   show. Click START GAME.

The one who joins (SLAVE):
1. In the start box "LAN game" -> Start -> JOIN SERVER.
2. SEARCH looks for servers in the network for 3 s; click a server in
   the list or type its IP address into "Server address". Through a VPN
   and between networks the search does not work - type the address.
3. Type your name (Your name, SLAVE) and click CONNECT.
4. Wait for the server to start the game - it begins by itself.

During the game:
- Both Amigas run the same game. Everything you do (building, roads,
  settings, attacks, pause P, speed + - 0) happens on both after about
  0.2 s (longer on a slow WiFi).
- The LAN line in the top left corner shows only when something is not
  right: WAITING - the game waits for the other side (a slow network);
  "OUT OF STEP" in red - the games went apart (please report it); also
  while a save is sent and when a player has gone. The option LANINFO
  shows it always: the other player's name, the response time,
  "same <step>" - both games agree.
- A screen larger than 640x480 becomes 640x480 for a LAN game
  (960x540: 640x360).
- Chat: Tab opens and closes the chat box (Esc closes it too), Return
  sends a line - up to 32 characters (letters, digits, space, - . : ? %).
  The name of the writer is in the colour of the writer's player. With
  the box closed a new line shows for 10 s, with the message sound.
  While the chat is open, letters and digits are not keys of the game.
- When one player leaves the game (or the link breaks), the other sees a
  notice and goes back to the start menu after 4 s.

Saving and going on:
- Save with the usual Save box. Saves of LAN games show a yellow LAN in
  the list (files name.lan.save).
- The one who sets up: Load game -> a LAN save -> Start (or a double
  click) opens the server box with that save; then RUN SERVER, START
  GAME. The save goes to the other Amiga, both go on from there. The
  server box can also choose a save with SAVED GAME.


ICON SETTINGS (Tool Types)
--------------------------

Select the Settlers icon, menu Icons -> Information. Entries in brackets
are off - remove the brackets to switch them on.

  FPS            frame counter in the corner of the screen
  MODE=640x480   resolution at the start (otherwise the one from Options)
  SFXAREA=ALL    sound effects from the whole screen (default: only from a
                 320x200 area around the centre, as in the original);
                 SFXAREA=480x300 - a larger one
  NOSOUND        no sound
  LANINFO        in a LAN game the LAN line always (player, response time,
                 games agreeing); without it only WAITING / OUT OF STEP
  DATA=path      another drawer with the game data (default PROGDIR:data)

Program stack in the icon: 1000000 (the game needs a large stack).


REPORTING BUGS
--------------

Give the version number (on the start screen, and "Version Settlers" in a
Shell). Press F10 when the bug happens: the game writes
RAM:Settlers-state.save and RAM:Settlers-state.txt - attach both files.
Changes of each version: Settlers_release_en.txt.

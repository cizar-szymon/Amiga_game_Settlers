THE SETTLERS (Freeserf) for the Amiga - version history
=======================================================

Reporting bugs: give the version number (start screen, "Version Settlers")
and attach RAM:Settlers-state.save and RAM:Settlers-state.txt, written by
the F10 key when the bug happens.


0.67 (26.10.2026, LAN branch - test build)
-------------------------------------------

- LAN game, step 2: the connection. RUN SERVER announces the server in
  the network, SEARCH finds servers (name and address), CONNECT joins.
  The server shows the name, address and response time of player 2,
  START GAME becomes active. The game over the network - the next step.


0.66 (26.10.2026, LAN branch - test build)
-------------------------------------------

- A wider LAN box: the labels and the IP addresses well apart.


0.65 (26.10.2026, LAN branch - test build)
-------------------------------------------

- The server box: the name MASTER at first (the one who joins: SLAVE),
  the IP address of this Amiga read from the network, no random number.
  A RUN SERVER button (STOP SERVER once clicked) - only then the server
  announces itself in the network.


0.64 (26.10.2026, LAN branch - test build)
-------------------------------------------

- A little smaller LAN on the icon. The LAN box: the name of this Amiga
  (the server is seen in the network by it, remembered), the server
  address, and for player 2 a name and an address on separate rows.


0.63 (26.10.2026, LAN branch - test build)
-------------------------------------------

- LAN game chosen third (after Start mission), a large LAN on the top of
  its icon; the server box has a "Player 2" row for the one who joins.


0.62 (26.10.2026, LAN branch - test build)
-------------------------------------------

- LAN game, step 1: a new game type "LAN game" in the start box (the
  game type icon). Start opens a START SERVER / JOIN SERVER box with an
  address to type. No network yet - only the windows.


0.61 (26.10.2026)
-----------------

- Fix: a saved game can be given any name - the letters (Z, I, P,
  digits, + - 0 ...) go to the name field and not to the game's keys.
  The name field is active as soon as the save box opens; Backspace
  works at the full length too; Esc closes the box.


0.60 (26.10.2026)
-----------------

- The Amiga box: a MC68040 clock 20-50 MHz in steps of 1 MHz (no
  revision - a 68040 does not tell it); a MC68060 as before, 50-100 MHz
  in steps of 10 MHz.


0.59 (26.10.2026)
-----------------

- The AMIGA button shorter (just its word), no longer up to EXIT.
- The Warp firmware with its dot (3.054).


0.58 (26.10.2026)
-----------------

- Options: a new AMIGA button next to ADVANCED - a box about the Amiga:
  the CPU and its revision, FPU, Kickstart, Chip and Fast memory, the
  graphics card and its memory, the screen mode. With a Warp accelerator
  (SYS:C/WarpTool): the model, the firmware and the CPU clock with arrows,
  50-100 MHz in steps of 10 MHz. Raising the clock (overclocking, may hang
  the system) only on a MC68060 rev. 6; it changes at once.


0.56 (26.10.2026) - release candidate
-------------------------------------

- The keys box wider (the key and its meaning in two columns).
- Pause (P): a large PAUSE in the middle of the screen (hidden while a
  box is open).
- A new icon: the "The Settlers" logo of the start picture on black, RTG
  in the top right corner (120x56).


0.55 (26.10.2026)
-----------------

- The settings box: the button says QUIT again (it still goes back to
  the start menu); a new "I" button between SAVE and EXIT shows the keys
  of the game. The I key shows the same box.


0.54 (26.10.2026)
-----------------

- No jerk when the magnification changes (the land is no longer drawn
  again, it took about 0.3 s).


0.53 (26.10.2026)
-----------------

- Options -> Advanced -> Invert scrolling inverts scrolling with the mouse
  both ways (it was only up and down). The cursor keys always scroll the
  way they point.


0.52 (26.10.2026)
-----------------

- A faster magnified map: only what changed goes to the card. 800x600:
  x2 30 -> 41 frames/s, x3 44 -> 50 frames/s.


0.51 (25.10.2026)
-----------------

- At 800x600 a second step of the magnified map: x3 (a view of about
  267x200, as in the original). The wheel up/down changes it by a step,
  Z goes through x1, x2, x3 and back.


0.50 (25.10.2026)
-----------------

- The map magnified 2x around the middle of the screen: the Z key
  (switches) or the mouse wheel (up: magnified, down: normal; AmigaOS 3.2
  or a NewMouse driver). Only above 400x300; the panel and the boxes stay
  as they are. The magnified view is even faster (a quarter of the map is
  drawn).


0.48 (25.10.2026)
-----------------

- Fix: after "Making the map" the map preview did not appear.


0.47 (25.10.2026)
-----------------

- The start menu: the map preview is made only when you stop clicking
  (MAPSIZE, mission, game type) - clicking MAPSIZE from 3 to 8 makes one
  map instead of five (about 5 s instead of 12 s). Meanwhile the preview
  area says "Making the map".
- Making a map about 20% faster (MAPSIZE 8: 6.4 -> 5.3 s on a 68060), the
  same maps as before.


0.46 (25.10.2026)
-----------------

- The EXIT label in the settings box in small letters, like the buttons
  beside it.


0.45 (25.10.2026)
-----------------

- The settings box in the game: its EXIT button (was QUIT) goes back to
  the start menu after the question instead of closing the game.
- The start menu: the QUIT button in the bottom right corner (was a small
  EXIT that only hid the menu) asks "Do you want to quit Settlers?" and
  Yes closes the game.


0.42 (25.10.2026)
-----------------

- Faster drawing of the landscape: the game starts in about 1.4 s instead
  of 3 s (the first picture of the map), a smaller jerk when scrolling to
  a new part of the map (about 58 instead of 75 ms per piece of land).


0.41 (25.10.2026)
-----------------

- A game speed other than normal is shown in the top right corner of the
  screen (X1.5, X2, X2.5, X3), like the frame counter; nothing at x1 and
  in a pause.


0.40 (25.10.2026)
-----------------

- Game speed keys: + speeds up to x1.5, x2, x2.5 and x3, - slows down but
  not below the normal speed, 0 goes back to normal. Before, + had no
  limit (up to x20) and - stopped the game. In a pause (P) + and - set the
  speed the game goes on with.


0.39 (25.10.2026)
-----------------

- The start picture stays for at least 4 seconds, with the music when it
  is on in the game.
- Fix: with the music off it played for a moment at the start. Now it
  does not start at all; switched on later (M, Options) it plays.


0.38 (25.10.2026)
-----------------

- Fix: buzzing, "overdriven" sound effects (hammer blows, digging,
  sawing, smithing). The sounds of serfs and buildings are started by the
  drawing and at a high frame rate started several times in one animation
  phase, cutting each other short. Now once per phase, as in the original.


0.37 (25.10.2026)
-----------------

- Paths and borders drawn once into the landscape tiles (again only when
  they change), not into every frame: a game with many roads 31 -> 44
  frames/s (640x400, 68060). Roads at the bottom edge of the screen are
  no longer cut off.


0.36 (25.10.2026)
-----------------

- Faster drawing of a map with many serfs: a game with some buildings and
  many carriers 14 -> 32 frames/s (640x400, 68060), the test scene
  43 -> 50 frames/s. The head of every serf is no longer decoded from the
  data in every frame.


0.35 (25.10.2026)
-----------------

- Sound effects only from around the centre of the map (a 320x200 area,
  the original's screen): at high resolutions many sounds no longer
  overlap. Tool Type SFXAREA=ALL - as before, from the whole screen;
  SFXAREA=WxH - another area. No effect on the speed.


0.34 (25.10.2026)
-----------------

- A start picture instead of a grey screen for the first seconds: the file
  data/start.iff (IFF ILBM), when it is there; without it the screen is
  black.


0.33 (25.10.2026)
-----------------

- Faster loading and saving: loading about 4 times faster (2.2 -> 0.6 s),
  saving about 7 times faster (3.4 -> 0.5 s) on a 68060. This also
  helps the autosave, the quick save (Ctrl+Z) and F10.


0.32 (25.10.2026) - first beta
------------------------------

- Freeserf with the data of the original Amiga disks.
- Picasso96 8-bit screen: 400x300, 640x400, 640x480 and 800x600, changed at
  once in Options -> Screen.
- Music (the module from the disks) and sound effects through Paula.
- The game's own cursor, scrolling with the mouse and the cursor keys.
- Options -> Advanced: Show FPS; options without a use on the Amiga hidden.
- Start from the icon, settings in Tool Types (FPS, MODE, NOSOUND, DATA).
- F9: screenshot, F10: state saved for a bug report.
- Speed: on a 68060 at 100 MHz (Warp7060) about 43 frames/s at 640x480
  while playing with music; the frame is put together in the card's
  memory, the card's blitter copies the landscape.

THE SETTLERS (Freeserf) for the Amiga - version history
=======================================================

Reporting bugs: give the version number (start screen, "Version Settlers")
and attach RAM:Settlers-state.save and RAM:Settlers-state.txt, written by
the F10 key when the bug happens.


0.127 (7.11.2026, beta release)
-------------------------------

- Pause (the P key): the whole game stands still - the computer players,
  the serfs, the buildings and the transport do nothing; while paused,
  nothing can be built, demolished or set (a refusal sound). The pause
  and the game speed work as always.
- LAN game: both sides need version 0.127.


0.126 (7.11.2026, beta release)
-------------------------------

- Large games much faster: the game logic (buildings, flags, serfs) runs
  several times faster - about 30 frames a second on a 68060 in a game
  with about 2500 serfs.
- Options -> Video -> Large games: when a large game is too much for the
  CPU - Smooth (the smoothest picture), Balanced (default), Full speed
  (the fastest game).
- Start menu: a percentage and a progress bar while a map is made; maps
  already made (new game, mission, tutorial) show at once when switching;
  START does not make the map a second time; maps are made about twice
  as fast.
- Options -> Amiga: the CPU clock in steps of 1 MHz (MC68060 rev. 6,
  50-100 MHz); without the WarpTool program the box shows the Warp card
  from the list of boards.
- LAN game: both sides need version 0.126.


0.125 (7.11.2026, beta release)
-------------------------------

- Languages: English, Polish and German (Options -> Language, the first
  row); the game starts in English, the choice stays for the next time.
  The translation files are in the po drawer next to the game.
- Options -> Font: the original font or a readable one (Readable) - in
  the same style, plainer letters, with small letters; the choice stays.
- Polish and German letters and the characters , ; ( ) / ' " ! + = etc.
  in the font of the game.
- The Options box is wider; at its bottom the buttons Advanced, Video,
  Audio, Amiga - the Exit of each goes back to Options.
- Options -> Audio: the sound through Paula or AHI (16 bits, e.g. the
  sound of a Warp card), music and effects on/off, the volume of all and
  of the music and the effects on their own (0-100 in steps of 10).
- Hints for all options: the left button held on the name of an option
  shows what it does.
- The 640x512 resolution (Options -> Screen, aspect 4:3).
- Start menu: no map size for a LAN game (the server chooses the map).
- LAN game: both sides need version 0.125.


0.124 (6.11.2026, beta release)
-------------------------------

- F10: the report RAM:Settlers-state.txt also gives the place of the map
  view and of the mouse pointer; the option VIEW=col,row (with LOAD=)
  sets the view there after loading - a bug report shows exactly what
  the player saw.
- The shores of the water are drawn whole, no black dots on the land by
  the water.
- LAN game: both sides need version 0.124.


0.123 (6.11.2026, beta release)
-------------------------------

- Options -> Video: "Terraforming wasteland" (off at first): foresters
  plant trees on sand first, and the sand around a new tree (its place
  and the 6 around it, up to the very edge of the desert) turns to grass
  for good, where buildings may stand; lumberjacks fell dead trees first
  (a few strokes, the tree is gone, no lumber); stonecutters break the
  brown boulders (no stone). New games and the game now, kept with the
  game; in a LAN game the server's setting.
- Options -> Video: the left button held on the name of an option shows
  what it does, letting go closes it.
- While a road is built the map always follows its end (Pathway
  scrolling is no longer in the Video box).
- LAN game: both sides need version 0.123.


0.122 (6.11.2026, beta release)
-------------------------------

- LAN game, Quit -> "Do you want to quit this game?" YES: under it the

  the LAN game, the game ends after the save; NO ends the game without
  a save. The other Amiga shows "The server ... ended the game." or
  "The player ... ended the game.". Neither side makes a LAN_ERR_...
  save then (only when the link is lost).
- LAN game: the names are PLAYER 1 (server) and PLAYER 2 (the one who
  joins) at first; typed ones stay for the next runs.
- LAN game: both sides need version 0.122.


0.121 (6.11.2026, beta release)
-------------------------------

- LAN game: both Amigas count the game the same way also after a resync
  and in a saved LAN game (new buildings, flags and serfs get the same
  numbers on both sides); what is on the screen does not change the
  game; demolishing a building that is no longer there (a second click,

- The + and - buttons of the game boxes (attack, knights of the military
  buildings, castle knights, the arrows of the transport priorities)
  repeat while the left mouse button is held.
- Save Game: a name of at most 25 letters (21 in a LAN game), what the

- Saves of normal and of LAN games apart: Load game and Save Game of a
  normal game list the normal saves, Save Game of a LAN game and LAN box

  server on the internet (being made, not working yet).
- The save at a sync error of a LAN game: SYNC_<yymmdd>_<hhmmss>M/S, the
  time with seconds.
- LAN game: both sides need version 0.121.

0.118 (5.11.2026, beta release)
-------------------------------

Options of the original (Options -> Video, first in the list):
- Pathway scrolling: while a road is built the map follows its end, as
  far as needed.
- Fast mapclick: a right double click on the map opens the map window.
- Fast building: a double click on an empty site (also on a tree stump)
  opens the building window, where only a flag fits it sets the flag,
  on an own flag it starts a road from it. With the map alone, no window
  open.

The mouse as in the original:
- The right button held + move: the map scrolls on and on, the pointer
  stays where the button went down (also with Invert scrolling).
- The right button held + the left one: on a building its window (an
  enemy's: attack), on the build button of the panel the building sites
  (with the sites for a flag alone), on the demolish button demolishing.
  The right button alone does not demolish, nor does the key 2.
- The right button does not close the building window.

The game:
- A demolished building without a road takes its flag with it.
- Map sizes 1 (32x32) and 2 (64x32); the chosen size stays after a game
  and in the settings.
- The map window keeps what it showed (land, roads, buildings, grid,
  zoom).
- Autosave every 3 and 5 minutes (besides 10, 20, 30, 60).
- Load game: a wide list of saves, no map preview. The Save Game box 2.5
  times as wide - the whole names of the files.
- Quick save Ctrl+Z: quick-<yymmdd>_<hhmmss>.save.

LAN game:
- A lobby once connected: the server chooses the map (SMALLER, LARGER,
  OTHER MAP, SAVED GAME), both see its preview and write in the chat
  (Return sends); the player who joined has the buttons CHANGE, AVERAGE,
  GREAT. START GAME on the server. In the start menu a LAN game makes no
  map.
- A new map in the start menu keeps the players (the second player stays
  a person).
- Show ping in LAN game (Options -> Advanced): the network's response
  time left of the FPS.
- When the game ends (a player leaves, the link breaks), both Amigas save
  it: LAN_ERR_<yymmdd>_<hhmmss>.
- When the games go apart (OUT OF STEP): both sides save SYNC_..M /
  ..S, then the server sends its game to the other player (resync) and
  both go on alike. Ctrl+Shift+R: a resync on request.

0.32 (25.10.2026) - first beta
------------------------------

- Freeserf with the data of the original Amiga disks.
- Picasso96 8-bit screen: 400x300, 640x400, 640x480 and 800x600, changed at
  once in Options -> Screen.
- Music (the module from the disks) and sound effects through Paula.
- The game's own cursor, scrolling with the mouse and the cursor keys.
- Options -> Advanced: Show FPS; options without a use on the Amiga hidden.
- Start from the icon, settings in Tool Types (FPS, MODE, NOSOUND, DATA).
- F9: screenshot, F10: state saved for a bug report.
- Speed: on a 68060 at 100 MHz (Warp7060) about 43 frames/s at 640x480
  while playing with music; the frame is put together in the card's
  memory, the card's blitter copies the landscape.

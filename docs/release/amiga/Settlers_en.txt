THE SETTLERS - Freeserf for the Amiga with a graphics card
==========================================================

Version 0.131 (beta), 8.11.2026

The Settlers (Die Siedler, Blue Byte 1993) on an Amiga with a graphics
card (Picasso96) and a 68040/68060, at up to 800x600 (4:3) or 960x540
(16:9). It is based on
Freeserf, the open source version of the game (GPL-3.0). The graphics,
sounds and music come from the original Amiga disks, which you need.


REQUIREMENTS
------------

- an Amiga 500 / 1200 / 3000 / 4000 with a Warp accelerator (Warp560,
  Warp1240, Warp1260, Warp1260 Extreme, Warp7060): the port is made and
  tested on these cards, and the fast graphics of the Warp give the
  resolutions and frame rates of this text. Other Amigas with a
  68040/68060 and a Picasso96 card run the game, but slower.
- tested on: A1200 + Warp1260 Extreme (68060, 100 MHz) and
  A4000 + Warp7060 (68060)
- AmigaOS 3.x, Picasso96 with 8-bit screen modes, about 32 MB Fast RAM
- the original The Settlers Amiga disks (3 disks)


GETTING STARTED
---------------

1. Copy the Settlers drawer to your hard disk.
2. Copy these files from the original disks to Settlers/data/amiga:
     from disk 3: gfxheader, gfxfast, gfxchip, sounds, extro
     from disk 2: gfxpics, music
3. Double-click the Settlers icon.

The game data is not in this archive - it comes from your disks.

Start picture (optional): the file data/start.iff - any IFF ILBM picture of
up to 8 bitplanes, shown while the game starts (at least 4 s, with the
music when it is on), scaled down to the screen.
Without it the screen is black while the game starts.

The intro of the original (optional): the original intro of the Amiga
game plays before the game when the drawer data/intro has its files from
your disks (intro.script is already in the drawer, it comes with the
game):
  disk 1: FHRS GA00 GA01 GA02 GAB2 GAC2 MUSI PIB1 PIC0 PIC2
          SML2 SMP0 SMP2 SPR1 US00 US02
  disk 2: GA03 GA04 KMSK KPIC PIB5 PIC3 PIC4 PIC6
          SMP3 SMP4 SMP5 US03 US04 US06
Any key or click goes on to the game; NOINTRO (Tool Type) turns it off.
Without these files the game starts at once.


CONTROLS
--------

  mouse                    everything in the game (as in the original)
  double click (empty)     the building window at once; at the start
                           of a game the castle; where only a flag
                           fits - a flag (option Fast building
                           in Options -> Video)
  double click (own flag)  a road from that flag (Fast building);
                           the flag window: right button
  right double click       the map window (option Fast mapclick)
  click on another site    the building window shows its buildings;
                           where nothing can be built it closes
  right held + left click  on a building: its window (castle,
                           lumberjack..., an enemy's: attack); on a
                           flag: the flag window; on the demolish button
                           of the panel:
                           demolishes (the right button alone does not)
  right button + move      scroll the map; the pointer stays where the
                           button went down, the map scrolls on and on
                           (as in the original)
  cursor keys              scroll the map
  Z, mouse wheel           the map magnified: x2 (above 400x300), x3 (800x600
                           and 960x540); none on 640x360;
                           the wheel up/down by a step, Z in turn
  P                        pause (again: continue), PAUSE on the screen
  1 ... 5                  panel buttons (not demolishing)
  B                        building sites (also: the left button on
                           the build button with the right one held)
  Tab                      next message; in a LAN game: the chat box
  +                        game speed: x1.5 / x2 / x2.5 / x3
  -                        slower, down to x0.5
  0                        normal speed (x1)
                           (a speed other than x1 is shown top right)
  M / S                    music / sound effects on and off
  Ctrl+Z                   quick save
  Esc                      close a box in the game
  Shift+Esc, Ctrl+Q        quit
  I                        a box with the keys (also the I button of the
                           settings box)
  QUIT (settings box)      leave the game for the start menu
  QUIT (start menu)        quit (after a question)
  F9                       screenshot to RAM:Settlers-shot.ppm
  F10                      bug report (saves the state, box to send it)


SETTINGS IN THE GAME
--------------------

Options:
  Language   the language of the texts: English, Deutsch, Polski (the
             files of the po drawer next to the game; the Polish and
             German letters drawn onto the font of the game)
  Font       the letters of the texts: Original (the font of the game)
             or Readable (plainer, in a similar style, with small
             letters); kept for the next start
  Messages   how many messages (None, Few, Most, All)
  Aspect     the shape of the screen, 4:3 or 16:9 (a click changes it;
             it always starts at the smallest resolution: 400x300 /
             640x360)
  Screen     resolution: the arrows next to it change it at once, within
             the chosen aspect - 4:3: 400x300, 640x400, 640x480,
             640x512, 800x600; 16:9: 640x360, 960x540; it is kept for the next
             start
Options -> Amiga:
  about the Amiga; with a Warp accelerator the CPU clock: only a MC68060
  rev. 6, 50-100 MHz in steps of 1 MHz (raising it overclocks, may hang
  the system); other processors without a change of the clock. The model, firmware and
  clock come from WarpTool (SYS:C, C: or SYS:Tools ...); without it the
  box only shows that a Warp card is there (from the list of boards, as
  ShowConfig), without the clock.
Options -> Advanced:
  Invert scrolling, Large numbers, Autosave, Stock box until occupied,
  Show FPS (frame counter in the corner),
  Show ping in LAN game (the network's response time, left of the FPS)
Options -> Video:
  (The left button held on the name of an option: what it does.)
  Sand on new maps (the deserts of new maps: None, 10% of normal
    ... Normal, - + buttons),
  Rocks on new maps (the brown boulders of new maps, the same way),
  Dead trees on new maps (the dead trees of new maps, the same way;
    in a LAN game the server sets it),
  More kinds of trees (mirrored trees and birches, only the look),
  Wild boars (boars among the trees)
  Terraforming wasteland (off at first): foresters plant trees on sand
    first, the sand around a new tree turns to grass for good (cacti
    and bones on it go); lumberjacks fell dead trees too (first, no lumber from them) and
    palms, stonecutters break the brown boulders (no stone); new games and the
    game now, in a LAN game the server's)
  Large games: when a large game is too much for the CPU - Smooth (one
    game step a frame: the smoothest picture, the game slower), Balanced
    (default: steps for about a frame of time), Full speed (up to five
    steps a frame: the game fastest, fewer frames). Small games run at
    full speed anyway.
Options -> Audio:
  Sound output: Paula (the sound chip of the Amiga, audio.device, 8 bits)
    or AHI (ahi.device, 16 bits: a sound card, the sound of a Warp card -
    warp.audio, or Paula through the AHI drivers; the mode in the AHI
    prefs). A click changes it at once, the choice stays for the next
    time; if AHI does not open, Paula stays.
  Music, Sound effects: the music and the effects on / off (also the keys
    M and S)
  Volume: the volume of all, 0-100 in steps of 10
  Music volume, Effects volume: the volume of the music and of the
    effects on their own, 0-100 (times Volume)

Settings are kept in Settlers.ini next to the game, saved games in the
freeserf drawer.


PLAYING OVER A NETWORK (LAN)
----------------------------

Two players on two Amigas (or an Amiga and an emulator, e.g. WinUAE or
Amiberry), and up to 2 computer players. In the same network (LAN) or
over the internet - through the game server of the author of the port
(INTERNET GAME, below), with nothing to set up in the router.

Needed:
- a TCP/IP stack (e.g. Roadshow) on both computers,
- the same version of the game on both (another version is turned away
  with a message),
- port 6810 (TCP and UDP) open between the computers; on a PC with
  WinUAE it has to be let through the Windows firewall. Another port can
  be typed into the "Port" field of the server box and of the join box
  (1-65535, kept in the settings) - both sides need the same one, also
  for SEARCH.

The one who sets up the game (MASTER):
1. In the start box switch the game type to "LAN game" (the icon with
   LAN on it, third after New game and Start mission).
2. Set up the map as in New game: size, random number, computer players
   (player 1 is you, player 2 the other person). Sand and rocks of the
   map: Options -> Video; the settings of this side count.
3. Start -> START SERVER. Type the name of the server (PLAYER 1), the port
   if needed (Port, 6810) and click RUN SERVER - the server announces
   itself in the network. The box shows the address of the Amiga in the
   local network (Server address) and on the internet (Internet address,
   "..." while it is checked, "none" without the internet).
4. When the other player joins, their name, address and response time
   show. Click START GAME.

The one who joins (SLAVE):
1. In the start box "LAN game" -> Start -> JOIN SERVER.
2. SEARCH looks for servers in the network for 3 s; click a server in
   the list or type its IP address into "Server address". Through a VPN
   and between networks the search does not work - type the address.
3. Type your name (Your name, PLAYER 2), the port of the server (Port,
   6810) and click CONNECT.
4. Wait for the server to start the game - it begins by itself.

Playing over the internet through the game server (INTERNET GAME):
1. Both players: in the start box "LAN game" -> Start -> INTERNET GAME.
   The field "Game server" holds the address of the game server
   (83.12.152.135:6810) - no need to change it. Type your name (Your
   name).
2. The one who sets up the game: type the name of the game (Game name),
   a password if wanted (Password; without one anybody can join) and
   click NEW GAME. The box shows the code of the game (4 letters) and
   "Waiting for a player..." - you can give the code to the other
   player. CANCEL GAME closes the game on the server.
3. The one who joins: the list "Games waiting" shows the games waiting
   for a player with the same version of the game (code, name, player,
   minutes of waiting; * - a game with a password); REFRESH asks for it
   again. Click a game in the list or type its code (Code of the game),
   the password if needed, and JOIN GAME.
4. Then as in the LAN: the one who set up the game chooses the map or a
   LAN save and clicks START GAME, both can write in the chat. The one
   who set up the game is its server (MASTER), the one who joined - the
   SLAVE.
- Only access to the internet is needed (TCP to port 6810); nothing to
  set up in the router. The game server passes the data between the
  Amigas and keeps the names of the games and players, the time of the
  game, the response times and the IP addresses (history of the games
  on the server). A game waiting without a player closes after 30 min.
- When the other player leaves, the game on the server ends; the box
  goes back to INTERNET GAME.

Playing over the internet without the game server (directly between
the Amigas):
- The one who sets up the game forwards the port of the game (TCP, 6810
  by default) in the router to the address of their Amiga (Server
  address in the server box).
- The one who joins types the internet address of the server (Internet
  address in its server box) into "Server address", and the same port.
  SEARCH works only in the local network.
- The game asks for the internet address once, when the server box
  opens: an HTTP question to api.ipify.org (port 80); the LAN server
  box sends nothing else.

During the game:
- Both Amigas run the same game. Everything you do (building, roads,
  settings, attacks, pause P, speed + - 0) happens on both after about
  0.2 s (longer on a slow WiFi).
- While the connection is fine, nothing about it is on the screen. A
  problem shows in yellow in the top left corner (where the FPS counter
  is; under it while the FPS are on):
    LAN: WAITING FOR <player>    the game waits for the other side
                                 (longer than 0.3 s - a slow network or
                                 the player does not answer)
    LAN: SLOW CONNECTION <n> MS  the response time is longer than the
                                 delay of the game's commands (usually
                                 160 ms)
    LAN: OUT OF STEP <step>      the games went apart (please report it)
    LAN: SENDING THE GAME <n>%   a save goes to the other player
    LAN: PLAYER GONE             the other player has gone
  The option LANINFO always shows the whole LAN line: the other
  player's name, the response time, "same <step>" - both games agree.
- A screen larger than 640x480 becomes 640x480 for a LAN game
  (960x540: 640x360).
- Chat: Tab opens and closes the chat box (Esc closes it too), Return
  sends a line - up to 32 characters (letters, digits, space, - . : ? %).
  The name of the writer is in the colour of the writer's player. With
  the box closed a new line shows for 10 s, with the message sound.
  While the chat is open, letters and digits are not keys of the game.
- When one player leaves the game (or the link breaks), the other sees a
  notice and goes back to the start menu after 4 s.
- When the games go apart (LAN: OUT OF STEP), both Amigas save the game
  of the same step: SYNC_<yymmdd>_<hhmmss>M (server) and ...S (the
  player who joined). Then the server sends its game to the other player
  (resync): that Amiga stops for a moment, loads it and both go on alike.
  In the chat: RESYNC DONE.
- A LAN game saves itself when it ends (a player leaves, the link
  breaks) - on both Amigas, the file LAN_ERR_<date>_<time of the end> (LAN in the
  list of LAN saves); go on with it as with any LAN save, below.

Saving and going on:
- Save with the usual Save box. In a LAN game the Save box lists the
  saves of LAN games only (files name.lan.save, a yellow LAN in the
  list), in a normal game the normal saves only; Load game at the start
  has the normal saves only.
- The one who sets up: in the server box LOAD GAME -> a LAN save -> USE
  GAME (or a double click); then RUN SERVER, START GAME. The save goes to
  the other Amiga, both go on from there. DELETE removes the chosen LAN
  save from the disk (after a question: YES / NO).
- Several saves at once (Load game and LOAD GAME of the LAN box): Shift
  click (or Ctrl click) marks more saves and unmarks them, a normal click
  goes back to one; DELETE removes all the marked ones (the question
  says how many).


ICON SETTINGS (Tool Types)
--------------------------

Select the Settlers icon, menu Icons -> Information. Entries in brackets
are off - remove the brackets to switch them on.

  FPS            frame counter in the corner of the screen
  MODE=640x480   resolution at the start (otherwise the one from Options)
  SFXAREA=ALL    sound effects from the whole screen (default: only from a
                 320x200 area around the centre, as in the original);
                 SFXAREA=480x300 - a larger one
  NOSOUND        no sound
  NOINTRO        no intro of the original before the game
  LANINFO        in a LAN game the LAN line always (player, response time,
                 games agreeing); without it only problems, in yellow
  DATA=path      another drawer with the game data (default PROGDIR:data)

Program stack in the icon: 1000000 (the game needs a large stack).


REPORTING BUGS
--------------

Press F10 when the bug happens: the game saves its state
(RAM:Settlers-state.save and RAM:Settlers-state.txt) and opens the bug
report box:
- Your e-mail - an address for an answer (not required, remembered),
- What happened - what happened, up to 1000 letters,
- SEND (or Return in the e-mail field) sends the report to the game
  server of the author of the port; CANCEL (Esc) closes the box without
  sending. Tab moves between the fields.
Sent are: the e-mail, the text, the version number, a description of the
Amiga (CPU and clock, Warp card, Kickstart, memory, graphics card, screen
mode) and both files of the state of the game. After sending, the box
shows the number of the report. The box shows only with a working TCP/IP
stack; without one F10 only saves the files - then attach them to a
report sent another way and give the version number (on the start
screen, and "Version Settlers" in a Shell).

When LAN games go out of step (LAN: OUT OF STEP), the other side sends
its files to the one who set up the game, and its game asks with the
same box whether to send the saves of both sides (SEND / CANCEL); the
game goes on.
Changes of each version: Settlers_release_en.txt.
